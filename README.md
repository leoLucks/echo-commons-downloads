# 回声仓下载

本仓库只托管回声仓的公开发行包与安装说明。应用源码仓库保持私有。

## Node.js 自托管版

- 支持 Windows、macOS 和 Linux。
- 需要 Node.js 22.13 或更新版本。
- 下载并解压 `echo-commons-node.tar.gz`。
- 在解压目录运行 `node server/start.mjs`。
- 浏览器打开 <http://127.0.0.1:4173/>。

该文件是 Node.js 自托管包，不是 `.exe`、`.dmg`、`.apk` 或 `.ipa` 原生安装器。

正式版本与校验值见 [Releases](https://github.com/leoLucks/echo-commons-downloads/releases)。
